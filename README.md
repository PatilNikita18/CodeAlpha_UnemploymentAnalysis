# Unemployment Analysis with Python

## Overview

This project analyzes unemployment rate data to identify
trends, regional differences, seasonal patterns, and the
impact of the COVID-19 period.

## Objectives

- Data cleaning
- Exploratory Data Analysis
- COVID-19 impact analysis
- Regional analysis
- Seasonal trend analysis
- Data visualization

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure

│
├── unemployment_analysis.ipynb

├── dataset.csv
└── images/

## Analysis Performed

1. Data Cleaning
2. Exploratory Data Analysis
3. Time-Series Analysis
4. COVID-19 Analysis
5. Regional Analysis
6. Urban/Rural Analysis
7. Seasonal Analysis
8. Correlation Analysis

## Conclusion

The project demonstrates how Python-based data analysis
can be used to understand unemployment trends and
regional variations.
